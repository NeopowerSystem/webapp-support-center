## PR 01｜建立 React UI 套件骨架

- [ ] 建立 React 19、TypeScript、Vite library mode 與本機預覽入口。
- [ ] 設定套件根入口、型別宣告及獨立 CSS 匯出。
- [ ] 將 React 和 React DOM 設為 peer dependencies，確認建置輸出未重複打包。
- [ ] 驗證乾淨安裝後可執行型別檢查、建置及本機預覽。

## PR 02｜固定 FAQ 資料、首頁與 RWD

- [ ] 建立 6 個分類、16 題固定 FAQ、5 個熱門入口，對照規格驗證各問題 ID 和文案。
- [ ] 完成首頁標題、導引、提示、熱門問題、分類卡片及聯絡客服入口。
- [ ] 依元件可用寬度調整版面，驗證 320、360、390、768、1024、1440 px 及桌面窄容器。
- [ ] 手機首頁對照圖稿，驗證文字可換行、觸控區域、鍵盤焦點及無水平捲動。

## PR 03｜完成分類、解答與導航

- [ ] 串通首頁、分類列表、FAQ 解答、已解決及返回流程。
- [ ] 驗證熱門與分類共用同一份解答，並在停止充電題提供拔槍異常連結。
- [ ] 支援指定問題 ID 開啟、未知 ID 回到首頁，以及返回有效來源頁。
- [ ] 確認 FAQ 可匿名瀏覽，各題均可進入聯絡客服。宿主尚未提供的外部操作隱藏。
- [ ] 驗證換頁焦點、返回焦點及長篇解答捲動。

## PR 04｜完成聯絡表單及 Email 回報

- [ ] 完成問題分類、問題選項、問題說明必填驗證。切換分類後重新選題。
- [ ] 支援選填聯絡手機與交易上下文。驗證手機前導 0、國碼與表單預覽往返時的草稿保留。
- [ ] 完成收件人、主旨及內文預覽，空白選填項標示「未提供」。
- [ ] 驗證複製信箱、複製問題內容、手動選取文字及 mailto 主旨與內文編碼。
- [ ] 驗證郵件啟動與失敗備援。客服電話僅在宿主有正式設定時顯示撥號入口。
- [ ] 驗證郵件欄位只帶入允許的資料，回報畫面顯示郵件草稿狀態。

## PR 05｜封裝 npm 候選版

- [ ] 確認套件名稱、scope、registry 和版本，整理安裝與整合 README。
- [ ] 用 npm pack --dry-run 核對產物，再用 npm pack 產生候選 tarball。
- [ ] 在乾淨 React 19 專案驗證 npm 安裝、元件匯入、CSS 匯入、FAQ 操作及 production build。
- [ ] 記錄候選版本與所對應的提交，交給 SmartHUB 整合驗收。

## PR 06｜SmartHUB 串接與端對端驗收

- [ ] 安裝候選版，接入會員中心、充電錯誤、付款錯誤和交易詳情的客服入口。
- [ ] 核對現有充電、場站、交易、載具及付款頁路由，驗證各宿主操作與來源頁返回。
- [ ] 驗證匿名瀏覽、登入後回到原問題，以及未授權交易無法帶入回報。
- [ ] 驗證五種結算狀態、單次更新付款及原流程重付條件。確認點選 FAQ 不觸發營運寫入操作。
- [ ] 驗證 iOS Safari、Android Chrome、iOS WKWebView、Android WebView 及桌面最新版瀏覽器的操作。
- [ ] 實測客服信箱可收件，確認承辦人。
- [ ] 整合驗收通過後發布正式版，將 SmartHUB 的套件來源改為 registry 並驗證安裝及建置。
